# FiolaLab web
Simulador educativo de densidad específica con tres pruebas, promedio, desviación estándar, coeficiente de variación, error relativo opcional y dos gráficos.

## Ejecutar localmente
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## Publicar
Sube `app.py` y `requirements.txt` al repositorio de GitHub y publícalo en https://share.streamlit.io . El archivo principal es `app.py`.
